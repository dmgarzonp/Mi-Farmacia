Respaldo y restauración

Base de datos SQLite

Los respaldos solo están disponibles en la aplicación de escritorio (Electron).

Si está usando el navegador, abra la aplicación instalada para crear o restaurar respaldos.

Crear respaldo

Guarda una copia de la base de datos en la ubicación que elija. Se recomienda hacerlo con frecuencia.

{{ loadingBackup() ? 'Creando...' : 'Crear respaldo' }}

Restaurar desde respaldo

Reemplaza la base de datos actual por un archivo .db de respaldo. La aplicación se reiniciará.

{{ loadingRestore() ? 'Restaurando...' : 'Restaurar' }}

Recomendaciones

  • Realice respaldos periódicos (por ejemplo, al cierre del día o de la semana).
  • Guarde los archivos .db en una unidad externa o en la nube.
  • Antes de restaurar, cierre cualquier otra ventana de la aplicación.
